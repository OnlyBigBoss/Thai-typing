# ใช้ Supabase สำหรับบัญชีและซิงก์ โดยเก็บข้อมูลในเครื่องเป็นหลัก

เว็บอยู่บน GitHub Pages ซึ่งให้บริการได้แค่ไฟล์หน้าเว็บ แต่ผู้ใช้ต้องล็อกอินเพื่อใช้ความคืบหน้าข้ามเครื่องได้ เราจึงใช้ Supabase (Auth + Postgres พร้อม Row Level Security) โดยหน้าเว็บเรียกใช้โดยตรง และยังใช้งานได้ครบโดยไม่ต้องล็อกอิน ข้อมูลทุกอย่างเขียนลง localStorage ก่อนเสมอ แล้วค่อยซิงก์ขึ้นคลาวด์เมื่อล็อกอินอยู่และเชื่อมต่อได้

## ทางเลือกที่พิจารณา

- **Firebase (Auth + Firestore)**: ทำได้ใกล้เคียงกันและไม่พักโปรเจค แต่ผู้ใช้เลือก Supabase
- **เขียนเซิร์ฟเวอร์เอง**: ต้องหาที่ host และดูแลระบบเอง ไม่คุ้มกับโปรเจคขนาดนี้

## ผลที่ตามมา

- Supabase แพ็กเกจฟรีจะพักโปรเจคถ้าไม่มีการใช้งาน 7 วัน จึงมี GitHub Actions ส่งคำขอทุก 3 วัน ห้ามลบ workflow นี้ทิ้งเพราะคิดว่าไม่จำเป็น
- ถ้า Supabase ใช้ไม่ได้ จะเสียแค่การซิงก์ ส่วนการฝึกพิมพ์ยังใช้ได้ตามปกติ เพราะข้อมูลอยู่ในเครื่องเป็นหลัก
- ระบบส่งอีเมลที่ Supabase มีให้ส่งได้เฉพาะอีเมลของทีม จึงต่อ SMTP ของ Gmail สำหรับอีเมลยืนยันและลืมรหัสผ่าน
- URL ของโปรเจคและ anon key อยู่ในโค้ดเว็บได้ ความปลอดภัยของข้อมูลมาจาก Row Level Security
