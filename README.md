# Thai-typing

โปรแกรมฝึกพิมพ์ดีดภาษาไทย (แป้นเกษมณี) มี 2 เวอร์ชัน ใช้เนื้อหาชุดเดียวกันจาก `data/words.json`

## เว็บ
เปิด `web/index.html` ในเบราว์เซอร์ได้เลย เวอร์ชันออนไลน์เผยแพร่บน GitHub Pages ทุกครั้งที่ push ขึ้น `main`

ระบบบัญชี (ล็อกอินเพื่อใช้ข้อมูลข้ามเครื่อง) ต้องตั้งค่า Supabase ก่อน ดู [docs/setup-supabase.md](docs/setup-supabase.md) ถ้ายังไม่ตั้งค่า เว็บก็ใช้งานได้ครบ แค่ไม่มีปุ่มล็อกอิน

ถ้าแก้ `data/words.json` ให้สร้างไฟล์ข้อมูลฝั่งเว็บใหม่:

```
python tools/build_web_data.py
```

## เดสก์ท็อป (Python 3 + tkinter)
```
python desktop/main.py
```

สถิติเก็บที่ localStorage (เว็บ) และ `~/.thai_typing_history.json` (เดสก์ท็อป)

## การใช้งาน
สลับแป้นพิมพ์ของระบบเป็นภาษาไทย (เกษมณี) แล้วพิมพ์ตามข้อความ — Esc หรือ Tab + Enter เพื่อเริ่มชุดคำใหม่ (รอบที่เริ่มใหม่กลางคันจะไม่ถูกบันทึก)

- เว็บมี 4 โหมด: บทเรียน, เวลา (15/30/60/120 วิ หรือ ✎ กำหนดเอง), จำนวนคำ (10/25/50/100 หรือ ✎ กำหนดเอง) และปุ่มอ่อน (เน้น 5 ตัวที่พิมพ์ผิดบ่อยหรือช้าที่สุด ใช้ได้หลังฝึกครบ 3 รอบ)
- หลังจบรอบจะขึ้นหน้าต่างผล: WPM ความแม่นยำ เวลา ตัวที่ผิดบ่อยและตัวที่ช้า และแผนที่ความร้อนของรอบนั้น (Enter = ชุดคำใหม่, Shift+Enter = ชุดคำเดิม, Ctrl+Enter = บทถัดไป)
- แถบบทเรียนบอกความคืบหน้าด้วยสี: ขอบเทา = ยังไม่ได้ฝึก, เทา = ฝึกแล้วยังไม่ผ่าน, เหลือง = ผ่านบท, เขียว = ผ่านดีเยี่ยม (ผ่านดีเยี่ยมแล้วจะไปบทถัดไปให้เอง)
- หน้าสถิติ (ไอคอนกราฟมุมขวาบน): กราฟ WPM แต่ละรอบ แผนที่ความร้อนสะสม และตารางตัวที่ผิดบ่อย เลือกช่วง 7 วัน / 30 วัน / ทั้งหมด และกรองตามโหมดได้
- บทเรียนที่ผ่านเกณฑ์จะมี ✓ ตั้งเกณฑ์ผ่านบท (ความแม่นยำ / ความเร็วขั้นต่ำ) ได้ที่ปุ่ม "เกณฑ์ผ่านบท" จะใช้เกณฑ์เดียวกันทุกบทหรือแยกแต่ละบทก็ได้ บทเรียนไม่ล็อกกัน เลือกบทไหนก็ได้
- สวิตช์ "คำจริง": เปิด = คำจริง, ปิด = ตัวอักษรสุ่มปนคำจริง (ในบทเรียนจะใช้เฉพาะปุ่มที่เรียนมาแล้ว)
- แป้นพิมพ์บนจอระบายสีตามนิ้ว (นิ้วเดียวกัน = สีเดียวกัน) และไฮไลต์ปุ่มถัดไป รวมถึง Shift ฝั่งตรงข้าม
- บทเรียน 20 บท เริ่มจากนิ้วที่ถนัดก่อน (ด ◌่ ก า ร ด้วยนิ้วชี้และนิ้วกลาง) แล้วเพิ่มทีละ 2–5 ปุ่มตามลำดับตัวที่ใช้บ่อย (อิงลำดับของ [pimsong.com](https://pimsong.com/lesson)) → Shift 3 ชุด → ตัวเลขไทยและสัญลักษณ์ → วรรณยุกต์ → คำควบกล้ำ → คำ → ประโยค → ย่อหน้า ทุกบทใช้เฉพาะปุ่มที่เรียนมาแล้ว
- ผังนิ้วอยู่ที่ `layout.fingers` และบทเรียนอยู่ที่ `lessons` ใน `data/words.json`
